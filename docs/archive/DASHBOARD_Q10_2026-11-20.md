# Q10 - Dashboard per peran memakai RPC `dashboard_overview` - 20 November 2026

## Perubahan

- `src/app/Dashboard.tsx`: untuk peran `administrator` dan `principal`, setelah profil dimuat dashboard memanggil satu RPC `dashboard_overview()` melalui `getDashboardOverview(client)` dari `src/lib/dashboard-overview.ts` (kontrak Codex, tidak diubah). Hasil RPC mengisi ringkasan registri aktif, tahapan supervisi, status modul ajar, dan tiga pengumuman terbaru beserta jumlah terbit/draf.
- Bagian baru: "Ringkasan data sekolah" (siswa/guru/kelas aktif dengan tautan ke daftar) dan, khusus kepala sekolah, "Ringkasan kepala sekolah" (pra-observasi, observasi, pasca-observasi, tindak lanjut, perlu ditinjau, dikembalikan) dengan tautan ke supervisi dan modul ajar. Masing-masing artikel memakai `aria-label` dan judul bagian `aria-labelledby`.
- Komponen `src/app/SchoolOverview.tsx` dan `src/app/PrincipalOverview.tsx` dihapus; keduanya memakai 3 + 6 hitungan `head` terpisah dan digantikan satu RPC.
- Jika RPC gagal, dashboard menampilkan `role="alert"` "Ringkasan dashboard belum dapat dimuat. Pilih Muat ulang untuk mencoba lagi." tanpa data palsu; tombol "Muat ulang" di header memicu muat ulang penuh (profil + RPC). Muat ulang mengosongkan `overview` lebih dulu sehingga nilai lama tidak tertinggal.
- Peran guru, siswa, wali, dan pending tetap memakai jalur pengumuman lama (tanpa RPC). `canReadAnnouncements`, `canManageAnnouncements`, dan helper RLS lain tidak berubah.
- Palet D8 dan tata letak mobile dipertahankan (tanpa aturan CSS baru; kelas `.dashboard-stats`, `.principal-metric`, `.principal-links` sudah ada).
