## Lingkup

- `src/app/Header.tsx`: navigasi per peran tetap memakai helper RLS yang sudah ada
  (`canReadMasterData`, `canReadAttendance`, `canReadJournals`, `canReadLearning`,
  `canReadAssessments`, `canReadSchedules`, `canAccessCommunication`, `canReadAnnouncements`).
  Tidak ada perubahan aturan akses; hanya penyajian.
- Desktop (>= 1000px): navigasi utama menjadi sidebar kiri tetap selebar 264px; konten bergeser
  lewat `body { padding-left: 264px }`.
- Ponsel (< 1000px): `bottom-nav` maksimal 4 tujuan cepat (Beranda, Dashboard, Data sekolah,
  Absensi) + tombol "Lainnya" yang membuka drawer berisi sisa menu. Label "Data sekolah" dapat
  membungkus dua baris pada 390px tanpa melampaui tinggi item.
- Drawer: `role="dialog"`, `aria-label="Menu lainnya"`, `aria-expanded`/`aria-controls` pada
  tombol pemicu, fokus pindah ke tombol Tutup, Escape menutup, klik latar menutup, fokus kembali
  ke tombol "Lainnya", dan drawer tertutup otomatis saat rute berubah.
- Target sentuh: item bottom nav >= 48px, tautan drawer/guest nav >= 44px. Kontras memakai token
  palet D8 (`--brand` #4C1D95, `--lilac` #EDE9FE).
